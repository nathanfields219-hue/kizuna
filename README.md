# Nubo

Le site de **Nubo**, le jeu de rythme où la balle rebondit sur ta musique.

- Site : https://nathanfields219-hue.github.io/nubo/
- Télécharger le jeu (Windows) : [Nubo.zip](https://github.com/nathanfields219-hue/nubo/releases/latest/download/Nubo.zip)
