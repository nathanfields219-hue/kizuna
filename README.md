# Kizuna

Le site de **Kizuna**, le jeu de rythme où la balle rebondit sur ta musique.

- Site : https://nathanfields219-hue.github.io/kizuna/
- Télécharger le jeu (Windows) : [Kizuna.zip](https://github.com/nathanfields219-hue/kizuna/releases/latest/download/Kizuna.zip)
